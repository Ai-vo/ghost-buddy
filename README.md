# Ghost Buddy

화면 구석, 작업표시줄 위에서 친구들의 유령과 함께 지내는 데스크톱 메신저예요.
작업하는 동안 친구 유령이 옆에서 떠다니고, 짧은 말은 말풍선으로 주고받아요.

## 설치

[최신 버전 받기](https://github.com/Ai-vo/ghost-buddy/releases/latest)에서 내 컴퓨터에 맞는 파일을 받아주세요.

| 운영체제 | 파일 |
|---|---|
| Windows 10·11 | `GhostBuddy-Setup-버전.exe` |
| macOS | `GhostBuddy-버전-mac.dmg` |

**Windows**: 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 눌러주세요.
새 버전은 자동으로 받아뒀다가 앱을 끌 때 설치돼요.

**macOS**: 처음 열 때 "손상되었기 때문에 열 수 없습니다"가 뜨면 터미널에 아래 한 줄을 입력해주세요.
새 버전이 나오면 앱이 알려주고, 위 링크에서 받아 덮어 설치하면 돼요.

```
xattr -cr "/Applications/Ghost Buddy.app"
```

## 사용법

- **내 유령 우클릭**: 설정 창 (닉네임·꾸미기, 그룹, 대화 기록, 낚시, 가방)
- **내 유령 더블클릭**: 채팅. `@닉네임`을 쓰면 그 친구를 부를 수 있어요
- **꾹 눌러서 들기 → 놓기**: 들었다가 떨어뜨리거나 휙 던지기
- **친구 유령 더블클릭**: 공 던지기

### 친구와 함께하기
설정 창 → 그룹에서 **그룹 만들기**를 누르면 초대 코드 6자리가 생겨요.
친구는 같은 화면에서 코드를 입력하고 **들어가기**를 누르면 돼요. 한 그룹에 최대 12명까지 함께할 수 있어요.

### 낚시
설정 창 → 낚시에서 시작하면 유령이 낚시터로 가요.
입질(`!`)이 왔을 때 유령을 클릭하면 더 좋은 아이템이 나오고, 함께 접속한 친구가 많을수록 희귀한 게 잘 낚여요.
낚은 모자·귀·이펙트는 가방에서 바로 장착할 수 있어요.

## 알아두기

- 그룹 대화는 최근 7일, 그룹마다 100개까지 보관되고 그보다 오래된 건 자동으로 지워져요.
- 5분 이상 컴퓨터를 쓰지 않으면 친구들 화면에서 내 유령이 졸고 있는 모습(자리 비움)으로 보여요.
- 끄기: 설정 창 → 정보 → 끄기, 또는 작업표시줄 트레이 아이콘 → 종료
